# Smart-Select — CMS Architecture Case Study

> **Private source · Documentation preview · Features require further verification**

Smart-Select is a private repository whose existing project documentation describes a content-management-style full-stack application. The codebase is organized as a **Laravel 11 API** and a **React dashboard**.

## Technology

| Layer | Stack |
|---|---|
| API | PHP / Laravel 11 |
| Dashboard | React / Vite |
| Data | PostgreSQL |
| UI integration | React Query |
| Authentication | JWT (as described in the internal README) |

## What this demonstrates

The documented project structure illustrates a split frontend/backend architecture, API integration and database-backed administration workflows. A detailed feature list, screenshots, tests and deployment claims will be added **only after verification**.

## Publication approach

The original repository is private. This case study does not disclose source code, seed accounts, passwords, database data or environment configuration. The internal documentation includes example development credentials; these must be reviewed and changed or disabled before any future public source release.
